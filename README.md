# Claude News Brief Agent
> 基于 Claude API + RSS 自动抓取新闻，生成每日Markdown新闻简报。

## ✨ Features
- 自动抓取RSS新闻源
- 调用Claude 3 智能摘要、整理结构化简报
- 自动保存为日期命名的 Markdown 文件
- 可扩展：飞书推送、定时任务、多数据源

## 📦 Install
```bash
git clone https://github.com/你的用户名/news-brief-agent.git
cd news-brief-agent
python -m venv .venv
pip install -r requirements.txt
